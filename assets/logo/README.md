# Whale-girl ASCII logo

`whale-girl.txt` is the punctuation-only ASCII artwork used by the installer.

- Original whale-girl character: [上善无形](https://space.bilibili.com/4456176).
  [Original statement](https://t.bilibili.com/1231977657712771073).
- DeepSeek-themed maid redesign and supplied character reference:
  [ZipZipPipe](https://space.bilibili.com/4168597).
  [Redesign statement](https://t.bilibili.com/1231980045693616162);
  [author's posts](https://space.bilibili.com/4168597/upload/opus).
- Changes: a simplified pixel-style interpretation of the waving character
  reference was generated with OpenAI's image-generation tool, then converted
  automatically to punctuation-only ASCII with Chafa. It is a derivative,
  not the reference artist's original drawing.
